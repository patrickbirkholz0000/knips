# Knips

Screenshots und kurze Bildschirmaufnahmen für macOS — mit Zensur für Bilder **und** Videos.
Native Menüleisten-App (Swift, ScreenCaptureKit), alles läuft lokal.

- Bereich, Fenster oder ganzer Bildschirm; Auswahl auf dem eingefrorenen Bildschirm mit Lupe
- Karten unten links: Klick öffnet, außerdem kopieren, anpinnen, herausziehen, wegklicken; Anzeigedauer frei in Sekunden
- Editor: Pfeil, Rechteck, Ellipse, Linie, Text, Nummern, Marker, Zuschneiden
- Zensur: Verpixeln, Unschärfe, Schwärzen — plus Auto-Zensur für E-Mails, IBANs, Telefonnummern,
  Kartennummern und API-Schlüssel (Texterkennung auf dem Mac)
- Bildschirmaufnahme als MP4 (30/60 fps, Countdown, Mauszeiger, optional Mikrofon)
- Video-Editor: kürzen, Zensurfelder mit Zeitbereich, Auto-Zensur, Export als MP4 oder GIF

Installieren: `scripts/install.sh` · Details für Entwicklung: `docs/ENTWICKLUNG.md`
